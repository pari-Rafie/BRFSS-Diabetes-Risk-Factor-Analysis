# BRFSS Diabetes Risk Factor Analysis

## Project Overview

Analyzed BRFSS health survey data to explore factors associated with diabetes and communicate findings through data analysis and visualization.

## Tools & Skills

* **Excel:** Data cleaning, analysis, and summary tables
* **SQL:** Data querying and analysis
* **Python:** Data analysis and visualization
* **Tableau:** Interactive dashboard development

## Analysis

Explored relationships between diabetes and selected health and lifestyle factors, including high blood pressure, BMI, smoking, and physical activity.

## Project Files

* `BRFSS_Diabetes_Excel_Analysis.xlsx` — Excel analysis
* `diabetes_analysis.sql` — SQL queries
* `diabetes_python_analysis.html` — Python analysis and results
* `Diabetes BRFSS Analysis.twb` — Tableau workbook

## Interactive Dashboard
[View the Tableau Dashboard](https://public.tableau.com/app/profile/pari.rafie/viz/DiabetesBRFSSAnalysis/DiabetesRiskDashboard)
## Key Findings

- The diabetes rate was 25.33% among respondents with high blood pressure, compared with 6.94% among those without high blood pressure.
- The average BMI was 31.96 among respondents with diabetes, compared with 28.10 among those without diabetes.
## Data Source

Behavioral Risk Factor Surveillance System (BRFSS), Centers for Disease Control and Prevention (CDC).
